# RAG Knowledge Base

Android aplikácia pre osobnú znalostnú databázu: dokumenty, hlasové poznámky a chat nad vlastnými dokumentmi.

## Stiahnuť

[Stiahnuť ragkb.apk](https://github.com/enthilza/ragkb-releases/releases/latest/download/ragkb.apk) · [Všetky vydania](https://github.com/enthilza/ragkb-releases/releases)

Android 8.0 alebo novší, 64-bit ARM.

## Inštalácia

1. Otvor odkaz vyššie na telefóne a stiahni APK.
2. Pri prvej inštalácii povoľ „Inštalovať neznáme aplikácie“ pre prehliadač alebo správcu súborov.
3. Ďalšie verzie si aplikácia nájde sama: kontroluje ich raz denne pri štarte a na požiadanie tlačidlom s číslom verzie v hornej lište.

Tento repozitár obsahuje iba zostavené APK, nie zdrojový kód.
